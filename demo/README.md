# Demo - React Accessibility Widget

Interactive demo to showcase and test the accessibility widget features.

## 🚀 Run Demo

```bash
npm run demo
```

Then open http://localhost:5173

## ✨ Features

- Live preview of widget positions
- Adjustable offsetX and offsetY
- Code preview for easy copying
- Sample content to test accessibility features
- Mobile responsive

## 📦 Build Demo

```bash
npm run demo:build
```

Output: `demo/dist/`
